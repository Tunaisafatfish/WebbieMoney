# Money & Expense Manager

A simple personal finance dashboard for tracking expenses, income, and account balances.

## Features

- Custom expense category management
- Fixed vs random spending tracking
- Category share percentage summary
- Bank account and credit card balance tracking
- Income entry and category percentage summary
- Local storage persistence in the browser

## Run

From this folder, start a local static server:

```bash
cd /Users/yingyingluqu/Documents/finance-manager
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
